# Грабли, уроки, разбор пропусков

## Чек-лист устойчивости нового парсера

Пройди перед первым деплоем — каждый пункт стоил кому-то из портфеля инцидента.

- [ ] Фильтр по **дате публикации**, а не по номеру: номер выдаётся при создании черновика, процедура может выйти через несколько дней (rts_tender 4078396 vs соседи).
- [ ] Список сортируется **по возрастанию** даты или проходится целиком каждый прогон: при «новые сверху» публикации во время прогона сдвигают хвост, и строки проваливаются между страницами.
- [ ] Чекбокс-группы фильтров **не отмечаются** «на всякий случай»: на rts-tender группа значит «только отмеченные», пустая — «без фильтра».
- [ ] Проверка, что фильтр реально применился (счётчик не равен всему реестру — utp_sberbank `FILTER_SANITY_MAX`).
- [ ] Пустая выдача («Нет записей», выходные утром) — валидный результат, не таймаут.
- [ ] Пороги «больше N строк» сравниваются с реальным итогом, а итог пейджера проверен на заглушки («из 9 900»).
- [ ] Пустая карточка (нет полей) → исключение, ничего не пишется и не помечается обработанной. `driver.get()` может тихо открыть страницу ошибки Chrome с `readyState=complete`.
- [ ] Признак «собрано» пишется последним и атомарно (`.tmp` + `os.replace`).
- [ ] Имена файлов обрезаются по **байтам** (≤200), а не символам.
- [ ] Папка дня — по дате публикации с карточки (список подписей даты зависит от типа процедуры).
- [ ] Время: в Docker UTC, на ВМ МСК; фильтр «сегодня» и `scraped_at` считаются осознанно (`MSK = timezone(timedelta(hours=3))`).
- [ ] Добор вчерашнего дня после полуночи.
- [ ] Ненулевой код выхода при сбое; алерт на любой сбой; алерт снаружи (pull/старт контейнера).
- [ ] Внешний таймаут + lock; браузер закрывается и в `finally`, и по SIGTERM; chromedriver не оставляет зомби.
- [ ] Предохранитель «N ошибок подряд» и немедленный выход при `InvalidSessionIdException`.
- [ ] Темп запросов задан и вынесен в env; при капче/бане — стоп прогона, а не долбёжка.
- [ ] Необязательные шаги (размер страницы, карточка заказчика, документ) не роняют прогон.
- [ ] tenders-api — best-effort, есть `--resend`.
- [ ] Тесты не ходят в сеть и не требуют `.env`; `wait_page_ready` замокан.
- [ ] Прогон на целевой ОС (Linux) до деплоя.

## Разбор пропуска: «почему не спарсена закупка N?»

Каждая проверка дешевле следующей — иди по порядку.

1. **Есть ли в архиве/state**: `ls /archive/selenium/<парсер>/*/N`, `grep -x N logs/processed_items.txt`. Нашлась — собрана; дальше смотри, дошла ли в tenders-api.
2. **Карточка**: реальная дата и время публикации, тип/способ процедуры. Номер о дате ничего не говорит.
3. **Логи прогонов после публикации**: сбои, пропуски из-за lock, «не удалось перейти на следующую страницу» (у rts_tender это обрывает проход), капча, таймаут. Был ли добор вчерашнего?
4. **Видна ли в поиске**: найди её поиском по номеру (ЕИС или площадки) **без фильтров**, затем добавляй фильтры парсера по одному. Не воспроизводи поиск ровно как парсер — так воспроизведёшь и его баг (ложный след 2026-10-30).
5. **Пагинация**: итог смотреть на последней странице, не на первой.
6. Нашёл причину → фикс + тест + досбор (`--date`/`FILTER_DATE_FROM`) + запись в базу знаний проекта.

## Прочие ловушки

- pproxy: учётные данные upstream пишутся после `#` (`http://host:port#user:pass`), а не `user:pass@` — иначе разбирает как шифр Shadowsocks («existing ciphers»).
- Строка `Upstream proxy:` в stdout содержит логин/пароль прокси — маскировать.
- API прокси (`edo.k-zakupki.ru/get_random_proxy/`) отвечает 403 с IP не из whitelist (машина разработчика) → резервный прокси из `.env`.
- Ссылки на документацию бывают не `<a>`, а `<form><input type=submit>` (rosatom) — искать и формы.
- `Content-Disposition` с кириллицей приходит в latin-1-кракозябрах — имя брать из разметки.
- Вид вёрстки карточки может отличаться по секциям/типам — разведай все типы, не один.
- Внешний формат архива (`information.json` у utp_sberbank — `repr()`) мог быть зафиксирован потребителем: менять только по согласованию, новые данные — в отдельный state-файл.
- Windows-машина разработки ≠ Linux-прод: `fcntl`, `/proc`, длина имён, `DISPLAY`.
- `fcntl`/`flock` — Unix-only; на Windows такие скрипты не запустятся, тестируй с моками.
