# База знаний: {{topic}}

Эта папка — база знаний по схеме LLM Wiki (Андрей Карпати). Ведётся скилом `llm-wiki`.

## Роли
- `raw/` — сырые источники. Неизменяемые: Claude их только читает.
- `wiki/` — вики, которую пишет и поддерживает Claude. Человек читает (удобно в Obsidian).
- Этот файл — схема: соглашения базы. Новые правила пользователя дописываются сюда.

## Операции
- **ingest** — добавить источник: `raw/` → страница в `wiki/sources/` → обновить связанные сущности и концепты → `index.md` → `log.md`.
- **query** — ответ по вики со ссылками `[[...]]`; ценные ответы сохраняются в `wiki/syntheses/`.
- **lint** — проверка: противоречия, устаревшее, сироты, битые ссылки, пробелы.

## Соглашения
- Язык страниц: русский.
- Имена файлов: kebab-case латиницей; ссылки — `[[имя-файла]]` или `[[имя-файла|Подпись]]`.
- Каждый факт — со ссылкой на страницу источника.
- Противоречия не затираются, а фиксируются в разделе «Противоречия».
- Журнал: `## [YYYY-MM-DD] тип | заголовок` в конце `wiki/log.md`.
