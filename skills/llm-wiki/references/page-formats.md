# Форматы страниц вики

## Общие правила

- **Имена файлов** — kebab-case латиницей: `andrej-karpathy.md`, `retrieval-augmented-generation.md`. Это удобно в shell и стабильно в ссылках. Человеческое название — в `title`.
- **Ссылки** — вики-ссылки Obsidian по имени файла без расширения: `[[andrej-karpathy]]` или с подписью `[[andrej-karpathy|Андрей Карпати]]`. Имена файлов уникальны во всей вики (Obsidian ищет по имени, а не по пути).
- **Язык** — язык базы из `CLAUDE.md` (по умолчанию русский). Термины можно давать с оригиналом: «дистилляция (distillation)».
- **Ссылка на источник** у каждого нетривиального факта: `… обучается на 15T токенов ([[2026-04-02-llama-paper]])`.
- **Без воды.** Страница — это сжатое знание, а не пересказ. Лучше короткая страница с плотными фактами и связями, чем длинная.
- Даты — ISO `YYYY-MM-DD`.

## Frontmatter

Обязателен у каждой страницы в `sources/`, `entities/`, `concepts/`, `syntheses/`:

```yaml
---
title: Человеческое название
type: source | entity | concept | synthesis
tags: [тег1, тег2]
sources: [slug-источника-1, slug-источника-2]   # на чём основана страница
updated: 2026-04-02
---
```

Для `type: source` дополнительно:
```yaml
raw: raw/2026-04-02-slug.md      # путь к сырому файлу
url: https://…                   # если есть
author: …
published: 2026-03-15            # если известно
```

## Страница источника — `sources/<slug>.md`

Slug совпадает с именем файла в `raw/` без расширения.

```markdown
---
title: …
type: source
…
---

# Название

**Кратко:** 2–3 предложения — о чём и почему важно.

## Ключевые выводы
- …

## Детали
Важные факты, цифры, аргументы, цитаты (в кавычках, дословно).

## Связи
- Сущности: [[…]], [[…]]
- Концепты: [[…]]
- Подтверждает / противоречит: [[…]] — в чём именно

## Оценка
Насколько надёжен источник, ограничения, что осталось неясным.
```

## Сущность — `entities/<slug>.md`

Люди, организации, продукты, проекты, места.

```markdown
# Имя

**Кто/что:** одна строка.

## Факты
- … ([[источник]])

## Связи
- [[…]] — характер связи

## Противоречия
(если есть) Источник A утверждает X ([[a]]), источник B — Y ([[b]]).

## История изменений
- 2026-04-02: … (кратко, только существенное)
```

## Концепт — `concepts/<slug>.md`

```markdown
# Название концепта

**Определение:** одно-два предложения.

## Суть
Объяснение своими словами, как для умного новичка.

## Как применяется / примеры
- …

## Связанные концепты
- [[…]] — чем отличается / как связан

## Источники
- [[…]] — что именно говорит
```

## Синтез — `syntheses/<slug>.md`

Сравнения, анализы, ответы на вопросы, сохранённые из Query.

```markdown
# Заголовок-вопрос или тема

**Вопрос:** исходный вопрос пользователя (если это сохранённый ответ).

## Вывод
Короткий ответ.

## Разбор
Таблица / аргументы со ссылками на страницы вики.

## Открытые вопросы
Что не удалось установить, какие источники нужны.
```

## index.md

Каталог по категориям; каждая строка — ссылка и одна строка описания. Порядок внутри раздела — алфавитный.

```markdown
## Источники
- [[2026-04-02-llama-paper]] — статья Meta о Llama 4, архитектура и данные
## Сущности
- [[andrej-karpathy]] — исследователь ИИ, автор идеи LLM Wiki
## Концепты
## Синтезы
```

## log.md

Только дописывается, новое — в конец. Единый префикс заголовка делает журнал грепабельным (`grep "^## \[" wiki/log.md`):

```markdown
## [2026-04-02] ingest | Название источника
## [2026-04-03] query | Сравнение X и Y → [[x-vs-y]]
## [2026-04-05] lint | 7 проблем, исправлено 5
```

Типы записей: `init`, `ingest`, `query`, `lint`, `edit` (ручная реорганизация, правка схемы).
